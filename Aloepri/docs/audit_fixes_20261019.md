# AloePri 本轮修复与验证

状态：CURRENT
日期：2026-10-19
上游依据：AloePri 论文与复现代码审核，以及本地修复后的测试记录
适用范围：本目录的研究实现、导出和攻击评测；不替代 fastProve 原有实验结论

## 修复了什么

- **扩维计算**：区分自定义归一化参考计算与标量近似，补上隐藏维度比例和 epsilon 尺度；修正 Q/K 置换方向，补 V/O 之间的变换；把 FFN 的置换、缩放和偏置处理写入权重。同一次残差相加的两路仍使用同一个输出矩阵 P。
- **模型入口**：对外词表映射与模型实际映射使用同一组置换；读取实际头宽和 RoPE 配置；拒绝不支持的层列表或架构。修复未传记录器、GPU/CPU 混用、低精度归一化统计和调试记录被重复覆盖的问题。
- **导出和客户端秘密**：修复不共享 Embedding 时漏改输出头的问题，让输出头噪声参数实际生效；新增原始 Qwen2 直接导出和分片权重读取；公开说明不再复制秘密种子和恢复参数；调试格式需要显式启用且不能用于标准发布。
- **交付检查**：非空导出目录不再被覆盖；拒绝非法 profile、Windows 名称碰撞和目录重叠；按完整权重名称和形状检查产物。确定性数值验收要求非空样本、有限数值、全部生成结果一致及误差不超过给定容差。
- **攻击评分**：删除向候选加入测试答案和未猜中时回填正确答案的做法；公开与私密语料分开；按各自 token 总数比较频率；修正小 Top-k、恢复率分母和句内 BLEU。IMA/ISA 的模拟已知配对训练必须显式启用，并在结果中说明。
- **说明和运行方法**：明确扩维研究程序与 Qwen2/Llama 同宽方阵导出的区别；补充依赖、独立测试及真实保存加载检查。具体命令见本目录 README。

## 已有验证

本地修复版本运行了以下命令：

```powershell
python -X utf8 -m pytest -q -ra --disable-warnings
```

实际使用的 Python 来自本地验证虚拟环境；版本与硬件记录见 [verification/environment_20261019.json](verification/environment_20261019.json)。完整输出见 [verification/pytest_20261019.txt](verification/pytest_20261019.txt)。结果为 **177 passed、32 skipped，0 failed**。跳过的 32 项包括 26 项缺少历史文档的检查和 6 项缺少真实模型或旧产物的检查，未计作通过。

验证覆盖逐层残差和模块计算、CPU/CUDA 上的 float32/float16/bfloat16 小模型前向、两层八头 Qwen2 的一轮小规模反演训练、safetensors 分片、导出发布后原生加载、8 个 token 的确定性生成，以及仅复制服务端文件后的独立加载。这里的随机小模型只验证计算和文件流程，不代表真实语言任务准确率。

这批测试在源 AloePri 项目中完成。本次复制保留源码，除 README 增加进入子目录的说明外，没有再次修改算法；未重跑 fastProve 原有测试。

## 仍需保留的限制

- 普通权重导出使用同宽方阵，明确标记 `paper_algorithm1_reproduced=False`，不是算法 1 的完整扩维复现。BERT 仍需自定义运行程序，只用于本地研究。
- Transformer SDA、优化输入的 ISA、Gate-IA/Attn-IA 和论文表 9 全部 VMA 组合尚未补齐；不能把当前结果称为通过了论文全部攻击。
- 未执行论文规模的预训练模型任务、PUPA 隐私实体实验、远程服务、vLLM/SGLang 或集群性能测试。
- 默认种子从系统随机源取得，后续仍使用 PyTorch 采样，不代表已经实现完整的密码学安全密钥方案。完整本地发布包含客户端秘密，只能交付规定的 server 目录。
- 对服务方按规定程序推理并观察普通输出的研究假设，不能扩展为能防御任意修改内核、挂接任意 hook、读取临时缓冲区或全部客户端秘密的攻击者；这些能力不在本实现的保护范围内。

论文公式和证明缺少条件的问题仍需独立澄清，不会因修改代码而自动解决。原论文可在 [arXiv v2](https://arxiv.org/abs/2603.01499v2) 阅读；下载的论文 PDF、模型和数据不随代码提交。
