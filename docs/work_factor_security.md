## 1. Problem Anchor

- **底线问题**：不要求攻击者永远无法恢复，而要求在同一观察范围、恢复质量和硬件口径下，攻击 fastProve 所需的最小计算成本显著高于对 AloePri、无噪扩维和其他选定基线的攻击成本。
- **必须解决的瓶颈**：不能只让深度学习攻击变慢，却保留一个便宜的伪逆、Gram、零空间投影或词表查表路径。安全性由攻击者可选攻击中最便宜的一条决定。
- **非目标**：IND-CPA、信息论不可恢复、差分隐私、抵抗任意恶意 kernel，以及没有条件的复杂度下界。
- **约束**：保持 exact/approximate 精度合同；防御端推理开销可测且受限；不依赖未实现的 TEE/MPC/HE；比较必须复用同一数据、模型、攻击调参预算和参考硬件。
- **成功条件**：在预先登记的攻击集合与两个观察视图下，达到同一恢复目标时，候选方案的攻击工作因子相对最强基线具有统计显著的倍率提升，同时不存在成本更低的代数旁路。

## 2. 安全对象：成本曲线，不是“可恢复/不可恢复”二值判断

给定方案 $s$、观察视图 $v$、攻击算法 $A$、目标数 $m$ 和恢复指标 $R$，定义攻击成本向量：

$$\mathbf C_{s,v,A}(m)=
(F,T,M_{peak},Q,O,D_{train}),$$

其中 $F$ 是估算 FLOPs/MACs，$T$ 是固定参考硬件墙钟时间，$M_{peak}$ 是峰值内存，$Q$ 是主动查询数，$O$ 是被动观测记录数，$D_{train}$ 是攻击训练数据量。原始结果必须保留完整向量，不能只报一个模糊的“攻击很慢”。

在固定硬件、查询和数据上限后，以参考时间或 GPU-hour 作为主排序标量 $C^{ref}$。对恢复目标 $\rho$，真实工作因子定义为：

$$W_{s,v}(\rho,m)=
\inf_{A\in\mathcal A_v}
\left\{C^{ref}_{s,v,A}(m):R_{s,v,A}(m)\ge\rho\right\}.$$

等价的预算—成功曲线是：

$$R^*_{s,v}(B,m)=
\sup_{A\in\mathcal A_v:\,C^{ref}_{s,v,A}(m)\le B}R_{s,v,A}(m).$$

方案 $s$ 相对基线 $b$ 的观测工作因子倍率和 bit 增益为：

$$G_{s/b,v}(\rho,m)=\frac{W_{s,v}(\rho,m)}{W_{b,v}(\rho,m)},\qquad
g_{s/b,v}=\log_2G_{s/b,v}.$$

$G>1$ 表示更难攻击；$G=10$ 表示在该恢复目标和实验合同下约十倍参考计算成本。它不是密码学安全位数。

实际只能评测有限攻击集合 $\mathcal S_v\subset\mathcal A_v$：

$$\widehat W_{s,v}=\min_{A\in\mathcal S_v}C^{ref}_{s,v,A},\qquad
W_{s,v}\le\widehat W_{s,v}.$$

因此 $\widehat W$ 是对真实最小攻击成本的乐观上界。报告只能说“对已评测攻击集合的工作因子”，不能说已经证明所有攻击都更贵。

## 3. 一次性准备成本与批量摊销

攻击往往包含密钥/子空间恢复和逐目标解码两部分。在每个 key epoch 都必须重新准备、且跨 epoch 不可迁移的条件下：

$$C_A(E,m)=E\,C_{setup}+m\,C_{target},$$
$$\overline C_A(E,m)=\frac{E\,C_{setup}}{m}+C_{target}.$$

所以只报单条 prompt 的攻击时间会夸大高准备成本防御；只报一百万条目标的摊销成本又会掩盖密钥轮换收益。至少报告 $m\in\{1,10^2,10^4\}$ 或由真实业务流量确定的三个规模，并给出 key epoch 中可观测目标数量。

密钥轮换只有在“跨 epoch 不可复用”经过迁移攻击验证后，才能把 $C_{setup}$ 重复计入。改变随机 seed 但保持可恢复的同一语义读取矩阵，不算有效轮换。

## 4. 最便宜攻击优先原则

### 4.1 公开投影右逆

若实际服务包满足

$$D_q=LB_q,$$

且公开 $B_q\in\mathbb R^{d\times m_q}$ 满行秩，则攻击者可计算

$$L=D_qB_q^+,qquad h=cL.$$

当 $m_q\ge d$ 时，一个稠密实现的准备成本上界约为：

$$O(m_qd^2+d^3+Nm_qd),$$

逐目标解码约为 $O(Nd)$。这是一个攻击上界，不是最优复杂度下界；使用结构、QR、迭代法或 GPU batched GEMM 可能更便宜。

只要这条路径存在，深度反演训练需要多少 GPU-hour 都不能代表方案工作因子，因为定义中的最小攻击会选择右逆路径。

### 4.2 concat 的统计子空间

expanded-concat 的总体秩至多 $d+r$，环境宽度为 $N=D+r$。对 $O$ 条同钥记录做随机化低秩分解，典型成本约为：

$$O(ON(d+r))$$

再加小矩阵分解成本。它至少可以估计固定支持子空间和 $D-d$ 个零空间方向；是否能进一步对齐到 token 由公开模型和其他可见参数决定。

### 4.3 full 的辅助空间消除

expanded-full 消除了上述固定协方差零空间，但若总辅助映射 $A\in\mathbb R^{(D-d+r)\times N}$ 可见，可以求 $\ker(A)$。薄 SVD 的稠密成本上界约为：

$$O\left(N(D-d+r)^2\right).$$

投影后仍保留全部 $d$ 维语义自由度。如果语义映射也已知，逐目标恢复仍是线性代数。full 的目标应是消除廉价的无参数 SVD 捷径，并迫使攻击者解决更昂贵的参数联合对齐；不能假设满秩本身已经产生高工作因子。

### 4.4 学习型攻击

只有在 Tier-0 代数路径不存在或已计入后，才比较优化型和学习型攻击：多初值 embedding inversion、浅层/深层 decoder、公开语料迁移、跨密钥迁移和语言模型辅助解码。记录训练、超参搜索和失败运行的总成本，而不只记录最终最佳 checkpoint 的推理时间。

## 5. 能真正提高工作因子的机制

候选机制按优先级排列：

1. **部署接口去除低成本旁路**：从真实 server bundle 检查是否存在 $D_q=LB_q$、公开 Gram、显式噪声读取或其联合等价式。不能通过删除日志或改变量名计入收益。
2. **expanded-full**：用补空间噪声消除 concat 的固定低秩 SVD 捷径，使攻击至少需要参数辅助对齐或学习型恢复。
3. **低可迁移的 key epoch**：分层、分 epoch 变换并验证旧 epoch 的攻击器不能直接迁移；同时记录防御端重新转换、分发和 cache 失效成本。
4. **逐请求刷新**：破坏固定 token 到固定向量的字典和重复匹配。它不会阻挡已经恢复固定 $L$ 的攻击。
5. **联合输出混合和结构隐藏**：避免单个公开投影直接给出 $LB$。所有下游抵消参数必须一起交给攻击审计，防止只把等式移动到另一层。

单纯增大 $r$、$\beta$ 或矩阵条件数不能自动提高最小攻击成本。过大的条件数首先损害正确性，且可能仍被稳定的伪逆或联合最小二乘绕过。

## 6. 攻击集合与公平比较

每个方案和视图运行相同的攻击层级：

| 层级 | 攻击 | 必记成本 |
|---|---|---|
| Tier 0 | 右逆/最小二乘、Gram、噪声零空间、SVD/PCA、范数/词表匹配 | 分解 FLOPs、时间、内存、记录数 |
| Tier 1 | 直接优化、已知分布最大似然、多初值反演 | 所有初值和失败迭代总成本 |
| Tier 2 | 学习型 inversion、跨密钥迁移、LM 辅助解码 | 数据生成、训练、搜索、推理总成本 |

基线至少包括：AloePri 可验证实现或明确标注的公式代理、expanded-concat、expanded-full、compact-direct 和无噪扩维。每个攻击使用相同硬件、软件、观测数据、标签隔离、最大调参次数和停止准则。可以为每个方案调参，但总搜索预算必须相同。

恢复指标至少包括 token top-1/top-5、候选覆盖、序列 exact match 和语义恢复指标。工作因子在相同 $\rho$ 上读取；未在预算内达到目标的运行作为右删失记录，不能把预算上限当成已测得成本。

## 7. 建议验收门槛

门槛是待项目负责人冻结的实验合同，而非已有结果。建议首轮采用：

- 主要恢复目标：token top-1 达到 10%、50% 两档，另报告完整曲线；
- 主要规模：每 key epoch 100、1,000、10,000 条记录；至少 3 把独立密钥；
- 基本通过条件：相对最强基线的 $G$ 的 95% 置信区间下界大于 1；
- 有意义的工程目标：预登记 `target_attack_cost_multiplier: 10`，即十倍工作因子，若未达到则如实报告；
- Tier-0 门禁：任何代数攻击达到目标的成本若与 AloePri 同阶且实测倍率无显著提高，则不能用昂贵 Tier-2 结果宣称安全提升；
- 防御成本同时满足项目既定 accuracy、latency、memory 和 bandwidth 约束。

若业务只要求“比对照更贵”，统计门槛仍应是置信区间下界 $>1$，避免把计时抖动写成安全收益。十倍目标用于形成值得部署和发表的效果量，不是数学必然值。

## 8. 允许的结论措辞

通过后可以写：

> 在 cloud_coa、给定模型/数据、攻击集合、参考硬件和恢复目标下，expanded-full 的观测攻击工作因子相对 AloePri 基线提高了 X 倍；防御端代价为 Y。未评测攻击与恶意 kernel 不在结论范围内。

不能写：

> 无法恢复、计算安全、达到 X bit 密码学安全、抵抗所有反演攻击。

## 9. 当前判定

当前只有代数恒等式、条件性攻击和小矩阵检查，没有同硬件攻击成本曲线，因此尚不能声称工作因子已经提高。已知右逆、Gram 和辅助空间投影给出了必须先测的低成本攻击上界。下一项安全任务应是对真实导出的 `expanded_concat` 与 `expanded_full` bundle 运行 Tier-0 攻击并记录完整成本，而不是先训练更大的反演网络。
